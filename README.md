# 🍽️ Restaurant Nakhah – Sales Analysis

## 📌 Project Overview

This project is an **Excel Sales Analysis project for Restaurant Nakhah (مطعم نكهة)**.

The workbook uses sales data to analyze restaurant performance from different perspectives, including **products, employees/customers, and monthly sales**.

The analysis is organized using Excel **Pivot Tables** to turn the raw sales data into clear summaries and business insights.

---

## 🎯 Project Objectives

The main objectives of the project are to:

- Analyze total sales for different products.
- Identify high-performing products.
- Analyze sales by employee/customer.
- Analyze sales performance across the months of the year.
- Compare sales between different products and time periods.
- Provide a clear overview of the restaurant's sales performance.

---

## 📊 Analysis Included

### 🍴 Product Sales Analysis

The project analyzes sales for a wide range of restaurant products, including:

- Main dishes
- Grilled items
- Rice dishes
- Appetizers
- Desserts
- Beverages

Each product is analyzed based on its total sales and monthly performance.

### 👤 Employee / Customer Analysis

The workbook includes separate sales summaries that allow performance to be reviewed by individual names and compared based on total sales.

### 📅 Monthly Sales Analysis

Sales are analyzed across all 12 months:

**January → December**

This makes it possible to identify changes in sales throughout the year and determine which periods generated higher or lower sales.

---

## 🧮 Excel Techniques Used

The project makes use of:

- **Pivot Tables**
- Sales aggregation using **SUM**
- Row and column grouping
- Monthly analysis
- Product-level analysis
- Employee/customer-level analysis
- Grand Total calculations
- Data summarization and comparison

---

## 📈 Business Insights

The analysis can help answer questions such as:

- Which products generate the highest sales?
- Which products have lower sales performance?
- Which month has the highest sales?
- Which month has the lowest sales?
- Which employees/customers have the highest sales?
- How does product performance change from month to month?
- What are the overall sales totals?
